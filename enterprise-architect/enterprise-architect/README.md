# Enterprise Architect Research Model

This directory contains the Enterprise Architect project used for the modeling and
transformation activities of the diamond supply-chain case study.

The project includes research artifacts associated with the CPDM/CPEM modeling
pipeline and the models used by the CPEM-to-Solidity transformation tool.

The project file can be inspected using Sparx Systems Enterprise Architect.

For broader research artifacts and modeling infrastructure, see the companion
CollabChain Platform repository.
